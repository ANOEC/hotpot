# 关于我们

## 战队介绍

### 赛事及团队历史

四川大学火锅战队是全国大学生机器人大赛RoboMaster机甲大师赛四川大学代表队，战队挂靠在校团委，由来自计算机、软件、制造、电气等不同学院不同年级的35个热爱机器人的同学组成。每年九月，战队根据比赛规则设计制作5~6个完备的机器人，到第二年五月代表四川大学参加机甲大师赛。战队隶属于四川大学校团委，同时得到制造学院、电气学院、计算机学院、软件学院的大力支持。战队在2017年12月得到制造学院的支持，和Robocon共同将制造学院楼219作为实验室，在15—17赛季比赛中名为“AK”，18赛季比赛正式改名为“火锅”，“火锅”俗而不失其韵，取自于日常生活，极富四川地方特色。寓意是希望战队的战斗力能如火锅般沸腾，战队的成绩能像火锅一样红红火火。

### 团队口号

沸腾不熄 火力全开

### 人员及管理

战队由校团委素质拓展部科员张韵老师负责管理，指导老师目前由制造学院的伍剑波副教授和电气学院的佃松宜教授担任。

根据性质不同，战队成员分为3个技术小组，分别为机械组、电控组、视觉组，和非技术的运营组；根据工作量不同，按照大约5:3:2的比例进行招收招收队员。
