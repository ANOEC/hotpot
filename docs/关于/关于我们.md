# 关于我们

## 战队介绍

四川大学火锅战队成立于 2015 年，是依托于四川大学机械工程学院的一支机器人战队，以“求是，团结，兢业，至臻”作为队训，是 RoboMaster 机甲大师赛四川大学参赛代表队。战队成员分别来自信电学院、机械学院、能源学院、控制学院等十数个学院，覆盖本硕博各个年级，分为机械、电控、视觉、硬件以及运营宣传五个小组。
