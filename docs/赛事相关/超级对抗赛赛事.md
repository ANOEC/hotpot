# 超级对抗赛赛事

RoboMaster 比赛以两队机器人之间的竞技攻防形式展开，机器人发射投掷
物命中对应目标造成伤害，比赛中共有 3 种可以发射的道具，分别为 42mm 大弹
丸、17mm 小弹丸和飞镖。英雄机器人可发射 42mm 大弹丸，步兵、哨兵和空中
机器人可发射 17mm 小弹丸，飞镖系统发射飞镖。

不同投掷物对不同目标可造成的伤害如图 2 所示，目标自身有血量数值，当
数值清 0 则判定单位阵亡或被摧毁。前哨站和基地则为如图 1 场地中的固定道
具，比赛场地尺寸为 28*15m，前哨站血量为 1500，基地血量为 5000。

比赛的胜负判定条件为：比赛时间结束时基地血量多的一方胜利，若基地血
量一致则比较前哨站血量，若前哨站血量一致则比较总输出伤害量。在前哨站被
摧毁的情况下才能对基地进行击打。

因此比赛的攻防首先围绕前哨站展开，由于前哨站姿态稳定可控，双方的英
雄和空中机器人往往成为击打前哨站的中坚力量，英雄机器人以其 200 伤害一发
的大弹丸可在短时间清空前哨站大量血量。同时空中机器人和哨兵机器人因其较
大的弹容量也往往成为击打前哨站的主力。

在前哨站血量清 0 后，基地将变为可击打状态，值得注意的是，基地拥有上
下两块装甲板和顶部一个飞镖检测模块可被击打，外形如图 4 所示。正常状态下
基地护甲闭合仅能击打上层装甲板，一些情况触发时基地护甲展开，下层装甲板
露出可被击打。上、下层装甲板可被 17mm 和 42mm 弹丸击打，飞镖检测模块仅
能被飞镖击打。但实战中上层装甲板由于位置和角度原因在大部分时候仅能被
42mm 弹丸从远距离吊射命中难度较大。因此实战中队伍也会尝试通过使敌方基
地护甲展开，来击打位置更低更容易命中的下层装甲板来获取优势。常用方式有：
1.飞镖固定、随机固定单局命中 4 发或随机移动、末端随机移动靶命中一发即可
打开基地护甲。2.占领敌方堡垒增益点 20s，也可打开基地护甲。基地护甲被打
开后无论小弹丸、大弹丸均可轻松命中基地装甲板以造成伤害。

在 26 赛季比赛中，由于各战队水平等因素参差不齐，比赛往往演化为以下
几种形式：1.有着强大的地面控制力和飞镖精准度的战队，通过地面压制强行占
领敌方堡垒或者飞镖 4 发全中等手段打开敌方基地护甲，英雄和步兵趁机击打下
层装甲板来取胜。2.飞镖和地面力量欠佳，但英雄远程输出能力较强的队伍，依
旧采取较为传统的英雄吊射击打基地上层装甲板的行为来获取优势。3.对于基地
打击手段不足的队伍，则将比赛退化到总伤害量的比拼，在击打完敌方前哨站后
整体采取保守态势趁机对敌方单位进行杀伤以取得优势。在区域赛中第 2 和第 3
种情况在很多情况下反复出现，但在国赛中由于战队整体水平的提升，第 1 种情
况将更为普遍的上演。

得益于 42mm 大弹丸对于前哨站和基地强大的爆发毁伤能力，英雄机器人在
数个赛季始终充当着“攻城重炮手”的角色。但 42mm 大弹丸带来的大号弹仓、
供弹机构和云台结构也使得英雄机器人普遍自重较大机动性欠佳，在被敌方步兵、
空中机器人等单位锁定时往往难以脱身。但作为战队关键伤害输出的核心，始终
拥有很高的研发优先级。

英雄的输出方式大体可分为近战优先和远程优先。近战优先的英雄通常游走
于中央高地和敌方半场，配合步兵机器人占领敌方堡垒快速爆发输出击打敌方基
地，技术上要求英雄机器人有良好的机动性和地形跨越能力方便快速机动。此战
术观赏性和效果极佳，但技术和战术实现难度偏高。远程优先的英雄则强化大弹
丸的外弹道表现，在己方半场进入部署模式远程吊射敌方基地上层装甲板以造成
伤害，因为战术层面实现难度整体较低而在过往几个赛季一直是英雄机器人的主
流方式，但官方在这个赛季引入了部署模式无法获取图传画面等机制，一定程度
上驱使英雄机器人往近战优先的路线研发。

相比较于英雄机器人的“玻璃大炮”，步兵机器人则更强调机动性和灵活性，
作为战队地面作战力量的核心，步兵的性能和操作手水平直接影响战队在比赛中
地面攻防的控制力。步兵发射 17mm 小弹丸，主要通过击杀敌方作战单位来取得
优势。

步兵机器人要求有先进可靠的自瞄算法，在短兵相接中可以快速锁定敌方装
甲板制敌。较快的小陀螺自旋速度提升扛击打能力。同时要有较强的地形跨越能
力，可以快速转进游走于各个地形之间。在必要时也加入对于前哨站、基地等关
键伤害的击打当中。
